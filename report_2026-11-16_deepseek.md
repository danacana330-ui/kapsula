# DeepSeek в панели ИИ капсулы — 2026-11-16

Добавил твою основную модель из Qwen Code прямо в список моделей капсулы.

## Что видно в панели «ИИ»

```
Qwen2.5 1.5B            1,0 ГБ · на компьютере
Qwen2.5 3B              умнее · 2,0 ГБ · не скачана
Бесплатная · авто       облако · нужен интернет
deepseek-v4.1-flash     свой сервер · api.aikeysforyou.com
gemma3:4b               3,4 ГБ · Ollama
...
```

Строка называется по имени модели и стоит выше списка Ollama, чтобы не искать её прокруткой.
Выбрана она же — панель открывается сразу на DeepSeek.

## Проверка живьём

- Список моделей прочитан текстом из живого окна — строка на месте.
- Отправил сообщение «ответь одним словом: работает» — ответ **«Да» за 5,3 с**.
- Тестовое сообщение из чата убрал, журнал ошибок `%APPDATA%\Kapsula\errors.log` пуст.

## Как это устроено

- Адрес, ключ и имя модели лежат в `%APPDATA%\Kapsula\settings.json` (поля «Своего сервера»),
  прежний файл сохранён рядом: `settings.before-deepseek.json`.
- **В коде ключа нет** — он только в твоём файле настроек на этой машине. Когда капсулу
  обновят другие люди, эта строка у них просто не появится, пока они не впишут свой сервер.
- Правка кода одна: строка «своего сервера» теперь подписана именем модели и поднята выше Ollama.
  Коммит `96bfa3b`, на GitHub не выкладывал.

## Что учесть

Ключ Aikeys теперь используется двумя клиентами — Qwen Code и капсулой. Если подписка считает
устройства или число запросов, при отказах причина скорее в этом, а не в коде: в ответе будет
ошибка сервера, и модель можно переключить на «Бесплатная · авто».
