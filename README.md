# Kapsula

Полоска-капсула вверху экрана Windows: музыка, время, погода, буфер обмена, заметки,
таймер, снимок и запись экрана. Рядом живёт маскот, который реагирует на Caps Lock,
сон и музыку.

## Скачать

Готовый файл — в разделе [Releases](../../releases/latest): `Kapsula-2.0.3.zip`.
Распакуйте архив и запустите `Kapsula.exe`. Устанавливать ничего не нужно, .NET 8 уже внутри.

При первом запуске SmartScreen покажет «Windows защитила ваш компьютер» — нажмите
«Подробнее» → «Выполнить в любом случае». Файл не подписан платным сертификатом.

Требования: Windows 10 (сборка 19041) или Windows 11, 64-бит.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Alt+Space` | панель запуска |
| `Alt+S`, `Ctrl+Shift+S` | снимок области экрана |
| `Alt+R`, `Ctrl+Shift+R` | запись экрана (повторно — стоп) |
| `Esc` | закрыть панель |

## Что умеет

- Музыка: обложка, название, исполнитель, play/pause, следующий/предыдущий (Windows SMTC)
- Громкость: ползунок в панели и индикатор на экране
- Буфер обмена: история копирований, карточка «Скопировано»
- Заметки: папки и поиск
- Полка файлов: перетащите файл на капсулу
- Погода сейчас и на несколько дней
- Таймер: идёт в фоне, на свёрнутой капсуле показывается вместо погоды
- Напоминания: заметка со временем, разбор фраз «завтра в 9», «через час», «18.11 в 14:30»
- Команды словами: таймер, напоминание, заметка, сводка, погода, курсы, громкость, яркость,
  тема, Wi-Fi и Bluetooth, снимок, запись, музыка, сайт, копия данных, блокировка экрана
- Быстрые действия: блокировка, сон, перезагрузка, выключение
- Точки микрофона и камеры, когда они используются
- Снимок области с рисованием и поиском картинки в интернете
- Автоскрытие в полноэкранных приложениях и играх

## Где хранятся данные

`%APPDATA%\Kapsula` — настройки, заметки, история буфера, полка.
Записи экрана по умолчанию — в `Видео\Kapsula`.

## Сборка из исходников

```
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o release\Kapsula-2.0.3
```

Нужен .NET 8 SDK и Windows 10/11.
